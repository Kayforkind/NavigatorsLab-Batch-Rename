📖 Detailed Step-by-Step User Guide

Step 1: Drop a Batch of Photos or Files to Rename · [Batch Dropzone (#dz)]Drag and drop a batch of photos or documents (`IMG_4821.JPG`, `DSC0092.JPG`, etc.) onto `#dz`.✓ Result: Files load and EXIF `DateTimeOriginal` timestamps (or file modified dates) are extracted.
Step 2: Choose Naming Pattern & Custom Slug · [Slug Source (#slugSrc) & Custom Slug (#slugText)]Select the naming rule in `#slugSrc` (e.g., `fixed` custom slug or cleaned original filename), type your label into `#slugText` (e.g., `site-inspection`), and configure sequence padding.✓ Result: Pattern rule (`YYYY-MM-DD--01.ext`) is configured.
Step 3: Click Preview New Names to Inspect Mapping · [Apply Preview (#apply) & Mapping List (#list)]Click **Apply (`#apply`)** and inspect the `Old Name → New Name` preview table in `#list`.✓ Result: Deterministic, collision-free filenames previewed side-by-side.
Step 4: Download All Renamed Files as One ZIP · [Download ZIP Button (#zip)]Click **Download ZIP (`#zip`)** to package all renamed files into a single local `.zip` archive via `JSZip`.✓ Result: Cleanly named archive downloaded while original files remain untouched.

🎛️ UI Controls & Shortcuts Reference

  • Batch Dropzone (`#dz`) — Accepts any number of images or documents for batch renaming.
  • Slug Mode (`#slugSrc`) & Text (`#slugText`) — Combines EXIF/file dates (`YYYY-MM-DD`) with a custom project slug and sequence numbers.
  • Apply Preview (`#apply`) — Updates the live `Old → New` filename table (`#list`).
  • Download ZIP (`#zip`) — Bundles all renamed files into one `.zip` archive.

💡 Pro Tips & Real-World Workflows

  • Combining photos from two different cameras (e.g., an iPhone and a Sony mirrorless)? Batch Rename sorts and names them by EXIF capture date so both cameras' shots interleave in true chronological order.
  • Use lowercase hyphenated slugs (`2026-11-08-client-workshop-01.jpg`) for web assets and S3/Cloudflare R2 uploads so URLs never contain `%20` spaces.
  • Your original files on disk are never overwritten—the renamed copies are delivered cleanly inside the downloaded `.zip`.
